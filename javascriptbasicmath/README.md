# JavaScript Basic Math

This folder contains 4 beginner-level JavaScript math logic questions with answers.

1. What is 12 + 8 * 3? -> 36
2. What is the average of 10, 20, 30, and 40? -> 25
3. Write a JavaScript expression to check whether a number is even. -> `number % 2 === 0`
4. What is the area of a rectangle with length 8 and width 5? -> 40

Run the script:

```bash
node math-questions.js
```
